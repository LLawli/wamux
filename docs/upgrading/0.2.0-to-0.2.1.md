# Upgrading from 0.2.0 to 0.2.1

No `.proto` field changes. whatsapp-rust moved to `eab45737` (#205), and the
library now imposes some behavior the core relays as is. The store needs no
migration.

## Operators

- **sqlx 0.9 (#209):** a Postgres `.pgpass` file now interprets backslash
  escapes. Check a password with a `\` in it.

## Edge authors

New refusals, all before anything is sent:

| RPC | Request | Now |
|---|---|---|
| `DeleteMessage` (for me) | someone else's message in a group or a status, without `participant` | `InvalidArgument` (the participant is now relayed, so deleting someone else's message works) |
| `StarMessage`, `DeleteMessage` (for me) | a channel message, or an empty message id | `InvalidArgument` |
| `DownloadMedia` | a media key or digest that is not 32 bytes | `InvalidArgument` (was `Unavailable`) |
| `SendPoll` | a broadcast list | refused by the library |
| `SendPollVote` | a channel or a broadcast list | refused by the library |

Changed answers and events:

- **`GetProfilePicture`** answers `ResourceExhausted` on a rate limit (a `429`
  inside `<picture>`), where it answered OK with an empty URL.
- **`GetAccountStatus` after `Logout`** reads `LOGGED_OUT`, matching the event.
  A stop keeps `LOGGED_OUT` and `BANNED`.
- **A CDN 403, 404 or 410** on a download is no longer refreshed and retried by
  the library. Retrying is the edge's call. A download URL no longer carries the
  `media_conn` `auth` parameter.
- **`raw_message`** follows the library's new schema: field 117
  (`newsletterAdminProfileMessageV2`) is gone, fields 132 to 134 can appear.
- **An enum value this build does not name** crosses as the wire enum's
  `UNKNOWN`, with the number in `mode_code` for the status audience.
- **Four library events arrive as `RawEvent`**: `ReachoutTimelockUpdate`,
  `CallLogHistory`, `UnarchiveChatsSettingUpdate`, `LabelSublistUpdate`. 0.2.2
  types them ([0.2.1 to 0.2.2](0.2.1-to-0.2.2.md)).
- **Under a heavy inbound burst** the library recycles the connection instead
  of queueing without limit: expect a `DISCONNECTED` then `CONNECTED` pair.

New RPCs, additive: `CallService.RejectCall` (#200), follow, unfollow, mute and
create a channel (#199), four group settings (#198), and block, unblock,
blocklist and `SetAbout` (#197).
