# Upgrading from 0.2.4 to the next release

Not released yet: this guide collects what the `[Unreleased]` section of the
CHANGELOG asks of you, and is renamed to the version when it ships. No `.proto`
field changes, and the store format is the same (0.2.4 opens a store the new
build wrote).

## Operators

- **Building from source needs no nightly:** the toolchain is stable `1.100.0`
  (`rust-toolchain.toml`), and `.cargo/config.toml` is gone.
- **SQLite creates a missing store directory**, mode `0700`, instead of failing
  to start.

## Edge authors

- **`DeleteMessage` with `for_everyone` follows the key's `from_me` (#276).**
  `from_me = true` is a sender revoke, as before. `from_me = false` with a
  `participant` in a group is now an admin revoke; the server refuses it with a
  `ServerAckEvent` carrying `error` `"403"` when the account is not an admin.
  `from_me = false` outside a group, or without a `participant`, is
  `InvalidArgument` (it used to go out naming a different message and deleted
  nothing).
- **After a reconnect, `monotonic_seq` order holds within each chat only.** The
  offline drain dispatches up to 8 stanzas at a time.
- **`RecipientFanout.addressed` counts hosted devices**, so it can be higher for
  a WhatsApp Business account on Coexistence.
- **Text and media inside a wrapper are projected** (spoiler, view-once,
  ephemeral, edit, `device_sent`, ...): `text`, `media` and `caption` are set
  where they used to be empty. `raw_message` still carries the whole payload.
- **`CreateAccount` with a taken `external_ref` answers `ALREADY_EXISTS`** on
  every engine (it was `INTERNAL`).
